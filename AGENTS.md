# Contribution rules

Keep canonical skills in skills/. Generate the Codex adapter with scripts/sync_adapter.py; do not edit its skill copies. Preserve existing user changes. Update VERSION and manifests together when releasing. Run scripts/validate_bundle.py and the unittest suite before contributing. Do not claim live packaging success from static validation. Read current primary sources before changing workflow guidance. Use PRs for future changes; do not merge or tag without user authorization.
